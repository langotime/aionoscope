# Research Inputs

- [docs/index.md](../index.md): return to the docs map.
- [papers/README.md](../../papers/README.md): repository-local paper material.

This section explains the role of research inputs in the repository.

## Policy

- `papers/` stores external research inputs, converted notes, and related working material.
- These files support design and benchmarking work but are not part of the package API or runtime validation harness.
- If a research artifact changes the public library story, propagate the durable result into [ARCHITECTURE.md](../../ARCHITECTURE.md), [README.md](../../README.md), or [DOCUMENTATION.md](../../DOCUMENTATION.md) rather than relying on paper notes alone.
